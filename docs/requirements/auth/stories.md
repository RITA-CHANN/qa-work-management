# Authentication user stories

| ID         | Story                                                                                                                                                                   | Priority | Source                        | Status   |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------- | -------- |
| US-AUTH-01 | As a **user**, I want to log in with my email and password, so that I can use the app.                                                                                  | Must     | Phase 2 business requirements | approved |
| US-AUTH-02 | As a **user**, I want to stay logged in when I reload or come back later, so that I don't have to log in every time.                                                    | Must     | Phase 2 business requirements | approved |
| US-AUTH-03 | As a **user**, I want to log out, so that nobody else can use my session on this computer.                                                                              | Must     | Phase 2 business requirements | approved |
| US-AUTH-04 | As a **guest**, when I open a page of the app, I want to be sent to the login page and then back to that page after logging in, so that I don't lose where I was going. | Must     | Phase 2 business requirements | approved |
| US-AUTH-05 | As a **user**, I want to see my name in the header, so that I know which account I am using.                                                                            | Should   | Phase 2 business requirements | approved |
| US-AUTH-06 | As the **business owner**, I want repeated wrong logins to be blocked for a while, so that nobody can guess passwords.                                                  | Must     | Phase 2 business requirements | approved |
