# Your tests live here

- `ui/` browser tests (project `chromium`), e.g. `navigation.spec.ts`
- `api/` API tests using the `request` fixture (project `api`), e.g. `health.api.spec.ts`

Run them from the repo root with `npm run e2e`, or `npm run e2e:ui` for UI mode.
See docs/PLAYWRIGHT.md for the current exercise.
